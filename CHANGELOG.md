# Changelog

## 2.0.0 — 2026-10-17

- Public-profile Fusion engine: GitHub/GitLab/Instagram/TikTok/Reddit, URL seeds, bounded public-link traversal and contact-link evidence.
- User Scanner parser attribution and optional pinned subprocess adapter (GitHub/TikTok).
- Append-only evidence review, relationships view and schema v2 migration with v1 backup.
- Editable DOCX, PDF relationship diagram and review notes; matching JSON/HTML data.
- Yellow/green/cyan terminal, original ASCII plus compact/mobile variants, skippable startup.
- README, actual PTY demo, live verification script and detailed source limitations.
- All v1.0.1 transport/profile fixes carried forward. Access file excluded from the release.


## 1.0.1 — 2026-10-17

- Added explicit, approved-host HTTPS proxy transport for networks where direct DNS is unavailable.
- Replaced built-in username HTTP-200 guesses with structured GitHub/GitLab/Reddit API validation and a negative username control.
- Enabled Sherlock --print-all so failed/negative sources survive CSV normalization. External tools now use the configured timeout and show actionable missing-interpreter errors.
- Added reproducible real CLI verification, online evidence exports and reports, plus 90 passing regression tests.
- Recorded actual domain/IP/email/web/metadata success and source gaps. Origin TLS direct, physical Termux and unavailable Nexray remain explicit limitations.

## 1.0.0 — 2026-10-17

- Original R_HMT terminal orchestration with 11 numbered menu entries and 24-cell ANSI emblem.
- Passive public-source domain/IP/email modules, explicit web/TLS requests, local file metadata.
- Isolated Sherlock/Maigret adapters and ExifTool process integration; upstream attribution and pin audit.
- Persistent SQLite cases/jobs/evidence, raw records, source-aware deduplication, cooperative cancellation and resume.
- Optional provider-neutral AI narration with preview, consent, draft review, limits and failure handling.
- Deterministic PDF/JSON/CSV/HTML/PNG reports, fonts, data digest and source references.
- Linux fresh-install validation, security/negative tests and report render inspection.
- Termux installer included; physical Android acceptance pending. Nexray live endpoint unavailable during release probe.
